Pass only if ALL hold:
1. Two or three concepts are presented.
2. The concepts differ in task flow or structure (for example when validation happens, how the user is guided, what the system does on a failed save), not only in visual styling, color or layout.
3. Each concept states a hypothesis.
4. Each concept describes its error state and at least one of empty or completion states.
5. Each concept lists trade-offs or risks.
6. The document does not pick a winner on its own authority; the choice is left to the PM (a labelled recommendation with the evidence that would change it is acceptable).
